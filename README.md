# MP3 + 静止画 → MP4 (GitHub Pages 向け)

ブラウザだけで、MP3 と静止画から MP4 を生成するシンプルなアプリです。

- 静止画を背景に固定
- オーディオスペクトラムを重ねて表示
- スペクトラムの透明度は **30%**
- 処理はすべてクライアントサイド（`ffmpeg.wasm`）

## 使い方

1. `index.html` を GitHub Pages で公開
2. 画像と MP3 を選択
3. 「MP4 を生成」をクリック
4. 完成した MP4 をダウンロード

## ローカル確認

```bash
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開いて動作確認できます。
